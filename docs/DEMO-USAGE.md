# Codex 用量演示历史

2026-11-15 起，主页改为**随机演示数据**，不再读取真实账户、NAS 或第三方用量接口。原接口服务本次不修改。

- 每日 token 为 3000 万～10 亿之间的整数。
- 日期种子 `moliang-demo-v1:YYYY-MM-DD` 生成稳定值，刷新、跨月和跨年不会重抽旧记录。
- 从 2020-01-01 起，按浏览器当前时间换算上海日期，只生成到昨天；今天和未来不生成、不计入合计，也没有可交互的网格记录。
- 静态页面挂载后计算日期，每分钟、回到前台或获得焦点时检查，并在上海零点附近刷新。无需服务器或定时构建，未来月份自动延长。
- 默认全部历史，可横向滚动（初始定位最新日期），也可按年份定位。累计视图始终累计全部早期记录，年份筛选不会重置累计。
- 本周仍按周一至周日统计，只包含已结束的日期；周一显示 0 token，周日尚未结束时只计周一至周六。
- 保留原万/亿格式、悬浮提示、每天/每周/累计标签和贪吃蛇。

实现：`components/demoUsage.ts`、`components/CodexUsage.tsx`。维护边界测试：

```powershell
node --test scripts/demo-usage.test.cjs scripts/usage-summary.test.cjs
```

此为前端装饰展示，不能用于推断真实消费、账户配额或账单。访问者修改本机时间会影响截止日期。将来如要重做整套演示分布，必须有意更换种子版本；不要在每次刷新时调用 Math.random 重抽历史。
